# Pantry Depths Demo 核心設計

給作者自己看的核心文件。不是規格書，不受本倉庫任何治理文件約束。

## 本文件的規則

**嚴禁私自參考。** 這份文件只寫作者講過的東西。任何沒講過的設計、任何從其他遊戲借來的機制，都不得寫入本文，也不得在後續實作中自行補上。有空缺就留空缺並提問，不要填。

**縫合怪。** 承認這是縫合而成的東西，這是接受的形狀，不是待修的缺陷。

**5 秒門檻。** 只要 5 秒內沒有幹死任何敵人或打壞任何東西，就是方向有問題。

## 一、關卡不得卡死

- 障礙物必須可被玩家通過，包括但不限於填平和拆除。
- 障礙物最好本身就提供遊戲機制——提供彈藥，或提供額外的死亡機制。
- 迷宮只是氛圍和機制的來源。不要給玩家迷路的機會，用輪廓投影解決。
- 不准有卡死的關卡。目前唯一的危險點是玩家開局被水坑圍起來，強制限制水坑不能圍成圓即可。

## 二、敵人

AI 必須簡單。敵人朝玩家移動：5 格外照 grid 巡路，5 格內直接朝玩家衝。

越下層越強，兩條軸：

- 特定 archetype 種類到某個深度才開始生成。
- Enemies 帶 Level，影響攻擊、防禦、血量。

## 三、右鍵：抓取

右鍵唯一的作用是抓取，抓取即使用物品。所有特殊效果都綁在被抓取的物品上，右鍵本身沒有任何變化，也不做替換。

現有物品：敵人、木棍、石塊、飛斧、炸彈。

未來預定：

| 物品   | 說明                     |
| ------ | ------------------------ |
| 標槍   | 對標木棍，但改由敵人掉落 |
| 火法術 | 取代炸彈                 |
| 冰法術 | —                        |
| 鐵扇   | 擊退敵人                 |
| 吸塵器 | 拉取敵人                 |

## 四、武器：主體與碎片

### 主體

武器的基底。武器之間的差別不是單純攻擊力不同，而是決定武器素材怎麼運作。

- 短劍：快、短距離、三連擊
- 斧頭：慢、範圍大
- 戰錘：慢、附帶擊退
- 長矛：直線穿刺、保持距離

普攻（左鍵，右手武器）要可以在準備階段替換。

### 碎片

附加的效果。暫時直接用 Bless 系統實作，等於開局直接贈送 Bless——碎片和 Bless 至少目前是同一個池子共用。

碎片和主體可以隨便搭配，一個武器最多裝 3 個碎片。

## 五、額外 Bless

要加進 Bless 欄目的項目：

- 第三刀爆炸
- 擊殺後一段時間內加速，可疊加並重置時間
- 被打有機率反傷
- 普攻有機率冰凍
- 正面無視傷害
- 血量鎖死 10，但閃避 99%
- 增加掉落拾取物機率
- 法術等級

## 六、地圖

半隨機半手作。一律 1 大 + 3 小，共 4 塊拼接而成。

**拼接方式**：大地圖擺中間，三個小地圖各找一邊，直接邊對邊貼上去，然後開個洞破磚牆連通。

**大地圖 21×21**：必定包含下層樓梯。

**小地圖 7×7**：四種，每層隨機抽 3 種，同一層不要重複抽到同類型。

| 小地圖   | 作用                                     |
| -------- | ---------------------------------------- |
| 祭壇     | 目前的 Bless 來源，未來廢棄              |
| 溫泉     | 回血                                     |
| 任務祭壇 | 達成條件後額外獲得 Bless，取代舊祭壇功能 |
| 血祭壇   | 詛咒物品，未來的搜打撤                   |

地圖可以手工製作後有機率被抽到，或完全隨機。手工地圖主要用來當新奇感，例如：下層樓梯在正中間，外圍 4 格護城河，玩家得一路填過去。

## 七、使命（task）

統一叫 task，省得以後想不開要做 NPC 和 Quest 系統。

樓梯有可能不再能直接到下一層，而是進入 Lock 狀態，必須達成條件才解開。條件形式：

- 擊殺定量敵人
- 使用特定方式擊殺定量敵人
- 到達某格站 3 秒
- 拆除定量牆體
- 找到鑰匙並成功丟到開鎖祭壇中

## 八、待加內容

- 鑰匙與門
